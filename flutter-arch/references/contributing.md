# Updating This Skill

When the user says things like "add this to the flutter skill", "remember this for flutter", "this should be in our flutter skill", "save this pattern", or otherwise indicates that a practice from the current session should be persisted into this skill, follow these steps:

1. **Identify the practice** — Look at the conversation to understand what rule or pattern the user wants captured. Distill it to its essence: what's the rule, why does it matter, when does it apply.

2. **Find the right place** — Re-read SKILL.md and the relevant reference file. Extend an existing section when possible rather than creating a new one. If it's already covered, say so instead of adding duplicate content.

3. **Draft the update** — Write it in the same style as the rest of these files: imperative voice, concise, with code examples when they clarify. Use GOOD/BAD comparisons when contrasting approaches. Explain the why briefly. Don't add bulk — a few lines is usually enough.

4. **Show the user and wait for confirmation** — Present exactly what you'll add and where before writing anything:
   - "I'd like to add this under **[Section Name]** in `references/[file].md`: [content]. Want me to go ahead?"
   - If modifying existing content, show before and after.

5. **Apply the edit** — Once confirmed, make a precise, minimal edit. Confirm briefly: "Done — added under [section]."

Keep this skill lean. Only codify practices that are genuinely recurring and worth enforcing across all future Flutter work. One-off or feature-specific details don't belong here.
